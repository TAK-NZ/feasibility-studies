## Sample adequacy
- offshore drogued, test set: 968 windows, 43 drifters -> enough for interpretation (but windows are correlated)
- offshore lost, test set: 1459 windows, 49 drifters -> enough for interpretation (but windows are correlated)
- coastal (<10 km), all selected: 35 windows, 13 drifters -> above the anecdotal thresholds
- coastal (<10 km), test set only (used for evaluation): 18 windows, 8 drifters -> ANECDOTAL: any coastal result is anecdotal

Selected offshore windows in total: 3940 (gate: at least 150) -> gate passed.
Anecdotal rule: fewer than 30 windows or fewer than 8 drifters.
Windows from one drifter, and windows on the same date, are correlated, so the effective sample size is closer to the number of drifters than the number of windows.

Not counted here: wind-speed classes need the downloaded GFS winds (done in the metrics step). Seasons are counted in step 15.
